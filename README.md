# Kite Browser

Windows용 **Kite Browser**와 **AI Kite** 설치 프로그램입니다.

## 설치 파일

[Windows 설치 파일 다운로드](Kite-Browser-Setup-2026.11.07-r3.exe) · [릴리스 기록](https://github.com/ReachToWisdom/Kite-Browser/releases)

r3 설치 파일은 설치 중 Chrome·Firefox·Edge 체크박스를 한 화면에 표시하며, 선택한 브라우저의 북마크를 Kite의 기존 북마크 저장소로 가져옵니다. 여러 브라우저를 동시에 선택할 수 있고, 브라우저별 프로필·신규 북마크·중복·오류 결과를 설치 완료 창과 `install-status.txt`에 남깁니다. 현재 Windows 사용자에게 두 브라우저를 설치합니다. 시작 메뉴의 A 항목에는 `AI Kite`를 독립 등록하고, K 항목의 `Kite Browser` 폴더 안에는 일반 `Kite Browser` 실행 항목을 둡니다. 업데이트 설치 시 실행 중인 두 모드를 경로와 PID로 확인해 정상 종료하고, 프로세스 종료를 확인한 뒤 파일을 교체합니다. 제거해도 사용자 설정과 북마크는 보존됩니다.
